# 我的新闻 · 设计规范（MASTER）

改界面以本文件为准。某个页面有特殊规则时写在 `pages/<页面>.md`，优先于本文件。

来源：2026-10-29 设计评审（Q31～Q36）。基于 ui-ux-pro-max 的「Minimalism & Swiss Style」+ 新闻编辑类字体推荐，
去掉了推荐里的粉红底色和 Google Fonts 依赖。

## 1. 风格

**报纸编辑风 × 瑞士极简**：留白多，严格网格对齐，用细线分隔，不用卡片阴影堆叠，不用玻璃拟态，不用大面积渐变。

- 首页是一份当期报纸：顶部报头（刊名、日期、早报 / 晚报），下面是「今日要点」和按分类分栏的新闻。
- 层级靠字号、字重、细线和留白，而不是色块。
- 图标统一用 Lucide（`lucide-vue-next`），线宽 1.75，尺寸 16 / 18 / 20；**不用 emoji 当图标**。
- 动效克制：只用于状态反馈（hover、按钮按下、展开），时长 150～200ms，尊重 `prefers-reduced-motion`。

## 2. 颜色（语义变量，组件里不写裸色值）

| 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--paper` | `#FAF9F6` | `#16140F` | 页面背景（暖白纸色） |
| `--panel` | `#FFFFFF` | `#1E1B15` | 输入框、弹层背景 |
| `--ink` | `#1F1D1A` | `#EDE9E1` | 正文 |
| `--muted` | `#6B655C` | `#A39C90` | 次要文字（来源、时间、说明） |
| `--rule` | `#E4DFD5` | `#2E2A22` | 细线、边框 |
| `--rule-strong` | `#1F1D1A` | `#EDE9E1` | 报头上下的粗线 |
| `--brand` | `#B91C1C` | `#F87171` | 朱红：只用于刊名、当前选中项、少量强调 |
| `--link` | `#1E40AF` | `#93B4F5` | 链接 |
| `--ok` | `#15803D` | `#4ADE80` | 成功 |
| `--warn` | `#B45309` | `#FBBF24` | 部分成功、提醒 |
| `--bad` | `#B91C1C` | `#F87171` | 失败、错误 |
| `--focus` | `#1E40AF` | `#93B4F5` | 键盘焦点环 |

- 对比度（已计算）：所有文字色与背景都 ≥ 4.5:1。浅色：正文 16.0、次要 5.5、朱红 6.2、链接 8.3、成功 4.8、提醒 4.8；
  深色：正文 15.2、次要 6.8、朱红 6.7、链接 8.8。
- 暗色模式跟随系统；顶栏可手动切换（`data-theme="light" | "dark"`，存 localStorage）。
- 朱红不做大面积背景；按钮主色用墨黑（`--ink` 底、`--paper` 字），保持报纸的克制。

## 3. 字体

不从 Google Fonts 加载（国内访问不稳）。

| 用途 | 字体栈 |
|---|---|
| 刊名、标题（衬线） | `"Newsreader", "Songti SC", "Source Han Serif SC", "Noto Serif SC", "SimSun", serif` |
| 正文、界面（无衬线） | `-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Segoe UI", sans-serif` |
| 数字、时间 | 无衬线 + `font-variant-numeric: tabular-nums` |

- Newsreader 用 `@fontsource/newsreader` 打包进项目（拉丁字符，400 / 600 / 700，约 100KB）。
- 正文 16px，行高 1.7；次要文字 14px；最小 12px（只用于角标）。
- 刊名 40～56px（手机 32px），衬线 700，字距 -0.5px。

## 4. 版式

- 内容最大宽度 1120px，左右留白 24px（手机 16px），不出现横向滚动。
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 断点：≥ 960px 新闻两栏；< 960px 一栏。
- 触控目标 ≥ 44×44px。

### 首页（本期）
1. 顶栏：左边导航（本期 / 历史 / 设置），右边语言、深浅色、退出。
2. 报头：粗细双线夹着刊名「我的新闻」；下一行是日期、期别、文章数；右侧是早报 / 晚报 / 历史期切换，以及「预览」「立即推送」按钮。
3. 「今日要点」（开了 AI 才有）：衬线小标题，编号列表，每条后附「原文」链接。
4. 分类分栏：衬线小标题 + 细线；每条新闻是标题（链接）、来源 · 时间、一句摘要。

### 设置页
左侧分组（FreshRSS、分类、早晚报、推送渠道、AI 摘要、系统），右侧表单；手机上分组变成顶部横向标签。

### 历史页
表格：期别、时间窗口、文章数、各渠道结果（成功 / 失败图标 + 渠道名），失败的可以「重新推送」。

## 5. 推送消息排版

```
我的新闻 · 早报 · 10月29日 周四
共 42 条，来自 8 个分类

【今日要点】（开启 AI 时才有）
1. ……

【科技】
1. 标题 — 来源
   一句话摘要
   链接
……
查看全部 42 条 → <链接>
```

Telegram（HTML）、钉钉 / Discord / 企业微信 markdown（Markdown）、Slack（mrkdwn）里标题是可点击的链接；其余渠道发纯文本。
超过渠道长度上限时拆成几条，标题加「（2/3）」，续页里重复所在分类的小标题并注明「续」。
